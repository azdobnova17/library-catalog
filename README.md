# Каталог книг в библиотеке

## Назначение проекта

Программа предназначена для хранения и поиска информации о книгах в библиотеке.

## Пользователи

- Читатель — просматривает каталог и выполняет поиск книг.
- Библиотекарь — добавляет, удаляет книги и изменяет их статус.

## Основные функции

- просмотр каталога книг;
- добавление книги;
- удаление книги;
- поиск книги по названию или автору;
- изменение статуса книги.

## Технологии

- Python
- Git
- Visual Studio Code

## Управление версиями

Проект хранится в Git-репозитории.

Для разработки используется отдельная ветка `development`, после чего изменения объединяются с основной веткой `main`.
